- (decision) Problem: NIST SP 800-53 Rev 5 is published as a several-hundred-page PDF; the government's own search tool is clunky. Build a fast, deep-linkable, phone-readable browser over the OSCAL catalog instead.
- (decision) Core capabilities named by user: filter by baseline, walk the control family tree, expand control enhancements inline, show related ISO 27001 clause on every control page.
- (decision) Primary audience: anyone who needs to quickly and thoroughly understand 800-53 controls without reading the full PDF -- security engineers, ISSOs, auditors, compliance managers, developers implementing controls. Broad/mixed, not a single role.
- (decision) ISO clause mapping sourced from NIST's own OSCAL crosswalk data, not user-maintained.
- (decision) Stakes: hobby/personal project. Target length ~2 pages.
- (decision) Form factor: web only, responsive (phone-readable browser page, not a native app).
- (decision) Data scope: NIST 800-53 Rev 5, full catalog, all baseline overlays (Low/Moderate/High/Privacy).
- (decision) Access model: public, free, no login required.
